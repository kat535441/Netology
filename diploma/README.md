**Дипломный проект: Система генерации изображений с автоматической валидацией качества**

- Описание проекта

Разработка end-to-end пайплайна генерации изображений по русскоязычным запросам, объединяющего три компонента:

* LLM (Falcon-3B / Qwen-2.5-3B) — преобразование русских запросов в англоязычные промпты

* Stable Diffusion (SD 1.5 / Dreamlike Photoreal 2.0) — генерация изображений

* CV (ResNet18) — автоматическая валидация качества

**Структура репозитория**

diploma/
├── data/                              # Датасеты для обучения LLM и тестирования
├── first_experiment/                  # Первый эксперимент (Falcon, 1000 примеров)
├── lora_output/                       # LoRA веса Falcon (расширенный датасет)
├── lora_output_qwen/                  # LoRA веса Qwen
├── models/                            # Финальные CV-модели (5 классов)
├── result_final.ipynb                 # Основной ноутбук с финальным пайплайном
├── requirements.txt                   # Зависимости
├── README.md
├── Диплом_Соловьева_ЕВ_DSU_77_v2_final.docx
└── Презентация_Соловьева_dsu_77.pptx

**Датасеты**
* Natural Images — обучение CV (8 классов)
https://www.kaggle.com/datasets/prasunroy/natural-images

* PASCAL VOC 2007 — класс other для CV
https://www.kaggle.com/datasets/zaraks/pascal-voc-2007 

* Синтетические промпты (GPT-4) — обучение LLM (1600 примеров)

**Установка**

pip install -r requirements.txt

**Запуск**

- Запустите result_final.ipynb в Jupyter Notebook. Ноутбук содержит весь код:

* загрузка и подготовка данных

* обучение Falcon-3B + LoRA

* обучение Qwen-2.5-3B + LoRA

* обучение CV-модели (ResNet18)

* тестирование финального пайплайна

* пользовательский сервис

**Результаты**

* Первый эксперимент (Falcon, 8 классов): точность CV 57%, точность пайплайна 43.8%

* Финальный эксперимент (Qwen, 5 классов): точность CV 88%, точность пайплайна 81.0%

* С регенерацией (до 3 попыток): точность пайплайна 88.8%
